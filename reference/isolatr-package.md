# isolatr: Simulate and Evaluate Isolation Testing Strategies for Infectious Diseases

Provides tools for simulating infectious disease transmission dynamics
during isolation/quarantine and evaluating the effectiveness of
different testing strategies. The package implements a stochastic
simulation model that accounts for household structure, vaccination
status, isolation timing, and various Test-Trace-Isolate-Quarantine
(TTIQ) scenarios. While defaults are calibrated to COVID-19, all
epidemiological parameters are configurable for other diseases. It
enables users to compare testing schedules and quantify their impact on
reducing onwards transmission from isolated individuals.
