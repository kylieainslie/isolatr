# isolatr: Simulate and Evaluate Quarantine Testing Strategies for COVID-19

Provides tools for simulating COVID-19 transmission dynamics during
quarantine and evaluating the effectiveness of different testing
strategies. The package implements a stochastic simulation model that
accounts for household structure, vaccination status, isolation timing,
and various Test-Trace-Isolate-Quarantine (TTIQ) scenarios. It enables
users to compare testing schedules and quantify their impact on reducing
onwards transmission from quarantined individuals.
