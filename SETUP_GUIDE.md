# isolatr Package Setup Guide

## What Was Done

All real datasets have been removed and replaced with a synthetic data generation system. The package now includes:

✅ Comprehensive documentation (roxygen2, vignettes, README)
✅ Code review with 16 issues identified and solutions provided
✅ Synthetic data generation scripts
✅ Complete data documentation
✅ Setup automation script

## Quick Start (Recommended)

From R, in the package directory:

```r
source("setup_package.R")
```

This will:
1. Generate all 11 synthetic datasets
2. Save them to `data/` directory as .rda files
3. Update package documentation
4. Load and check the package
5. Confirm everything works

## Manual Setup (Alternative)

If you prefer to do it step-by-step:

### Step 1: Generate Synthetic Data

```r
source("data-raw/create_synthetic_data.R")
```

This creates 11 data objects:
- `hhsize.dat` - Household sizes by state
- `distn.dat` - Detection time distributions
- `optimal.tat.dat`, `partial.tat.dat`, `nsw.ci.tat.dat` - Test turnaround times
- `optimal.interview.dat`, etc. - Interview delays
- `optimal.cc.notify.dat`, etc. - Notification delays

### Step 2: Update Documentation

```r
library(devtools)
devtools::document()
```

This generates:
- NAMESPACE file with proper exports
- .Rd files in `man/` directory
- Documentation for all datasets

### Step 3: Load and Test

```r
devtools::load_all()

# Test that data is available
head(hhsize.dat)
summary(distn.dat)

# Test a basic function
?CQ.sim2
?abbreviate_states
```

### Step 4: Try an Example

```r
library(dplyr)

# Run a small simulation
set.seed(42)
results <- CQ.sim2(
  n.ind = 100,
  TP = 2.0,
  k = 0.3,
  p.vac.idx = 0.7,
  p.vac.sc = 0.7,
  vacc.cor = 0.8,
  VE.trans = 0.5,
  VE.inf = 0.7,
  quarantine.duration = 14,
  the.scenario = "optimal",
  the.state = "NSW"
)

# Check output
head(results)
table(results$who)
```

## Building and Installing

### Build the package

```r
devtools::build()
```

### Install locally

```r
devtools::install()
```

### Run full checks

```r
devtools::check()
```

Note: You may see some warnings/notes - this is normal for a new package. Key things to check:
- No ERRORS
- Functions can be loaded
- Examples run (if eval=TRUE)

## Using Real Data (Optional)

If you have real data you're authorized to use:

1. Edit `data-raw/create_synthetic_data.R`
2. Replace the generation code with loading your real data
3. Ensure data format matches the documented structure
4. Rerun the script to create .rda files
5. Update `R/data.R` documentation if needed

**Important:** Never commit real data to the public repository. Add data files to `.gitignore` if they contain sensitive information.

## Troubleshooting

### "Object not found" errors

If you get errors about missing data objects:
```r
# Regenerate data
source("data-raw/create_synthetic_data.R")
devtools::load_all()
```

### "Function not exported" errors

```r
# Make sure @export is in roxygen blocks
# Then regenerate NAMESPACE
devtools::document()
devtools::load_all()
```

### Package won't load

```r
# Check for errors
devtools::check()

# Look at specific issues
devtools::load_all()  # Will show detailed error messages
```
